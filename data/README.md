# Revenue data source

`hospital_revenue_raw.csv` is the daily hospital-revenue series provided for WGU D603 Task 3. It contains 731 consecutive days. The other CSVs are prepared splits and forecast-evaluation outputs derived in the notebook. Forecast errors are expressed in the source revenue units.

The course materials reviewed identify the dataset and scenario but do not state an upstream redistribution license. The repository’s MIT license covers the project code, not a new license grant for third-party data. No claim that the records are synthetic is made.
